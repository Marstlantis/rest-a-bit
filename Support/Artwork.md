# 歇哈嘛角色素材

用内置 ImageGen 为四边入场生成两张独立的透明原画，再用 `script/prepare_art.py` 裁切为对齐脚底和躯干的 12 张姿态图。运行时由 Core Animation 播放动作序列与位移，逐帧绘画、插值和退出时机可以独立调节。

- [主要姿态](Art/primary.png) 包含探头、伸展跑姿、收腿跑姿、急停、抬头、趴下。
- [补充姿态](Art/gestures.png) 包含站定、回头、伏下、迈步、伸懒腰、落地。
